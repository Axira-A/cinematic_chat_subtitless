# HUD 편집기

[English](../en/hud-editor.md) · [简体中文](../zh-CN/hud-editor.md) · [日本語](../ja-JP/hud-editor.md) · [한국어](../ko-KR/hud-editor.md)

`/cchat hud` 또는 `/cinematicchat hud`로 엽니다. 설정 화면의 HUD 버튼은 부모 화면의 작업 사본으로 같은 편집기를 엽니다. 미리 보기는 일반 렌더러와 별도 대기열을 사용하며 Steve와 Alex의 현재 언어 환영 메시지를 표시합니다.

1. 자막 영역 안을 드래그해 이동합니다.
2. Shift를 누르고 세 논리 픽셀보다 멀리 움직이면 축을 고정합니다. Shift 상태가 바뀌면 드래그 기준점을 갱신하여 위치가 튀지 않게 합니다.
3. 좌우 가장자리로 줄바꿈 너비를 바꿉니다. 글자 배율은 유지합니다.
4. 오른쪽 아래 모서리로 전체 배율(0.5–3.0)을 바꿉니다.
5. 아홉 기준점 중 하나를 선택합니다. 맞춤과 안전 영역을 전환하고 드래그를 놓을 때 Alt를 누르면 맞춤을 잠시 해제합니다.

중심선과 안전 영역은 배치의 기준입니다. 위치와 너비는 정규화하여 저장하므로 해상도가 바뀌어도 비율을 유지합니다. 위치, 크기 및 HUD 초기화는 각각 사용할 수 있습니다. 미리 보기 다시 재생은 환영 문장을 처음부터 표시합니다.

기본 프리셋은 영화, 간결, RPG, 모험, 접근성 및 기본 스타일입니다. 이름을 입력하여 개인 프리셋도 저장할 수 있습니다. 시각 설정만 저장하며 사용자 이름은 그대로 유지합니다. 먼저 편집기의 작업 사본에 추가됩니다.

**직접 열었다면 적용으로 HUD 및 프리셋을 `config/cinematic_chat/`에 저장합니다. 설정 화면에서 열었다면 적용은 부모 화면에 변경을 전달하며 부모 설정 화면에서도 저장해야 합니다.** 취소 또는 Esc는 현재 화면의 작업 사본을 버립니다. 부모 설정의 취소는 자식 화면에서 전달한 변경도 버립니다.
