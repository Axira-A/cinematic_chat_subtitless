# HUD エディター

[English](../en/hud-editor.md) · [简体中文](../zh-CN/hud-editor.md) · [日本語](../ja-JP/hud-editor.md) · [한국어](../ko-KR/hud-editor.md)

`/cchat hud` または `/cinematicchat hud` で開きます。設定画面の HUD ボタンも同じエディターを開き、親画面の作業コピーを使います。プレビューは通常の描画と独立したキューを使い、Steve と Alex の現在の言語の歓迎文を表示します。

1. 字幕領域の内側をドラッグして移動します。
2. Shift を押し、三論理ピクセルを超えて移動すると軸を固定します。Shift の状態変更時は基準点を更新して飛びを防ぎます。
3. 左右の端で折り返し幅を変更します。文字の倍率は変わりません。
4. 右下の角で全体の倍率（0.5～3.0）を変更します。
5. 九つのアンカーから選択します。スナップとセーフエリアを切り替え、ドラッグを離す際に Alt を押すとスナップを解除できます。

中心線とセーフエリアは配置の目安です。位置と幅は正規化して保存し、解像度が変わっても比率を保ちます。位置・サイズ・HUD のリセットは個別に行えます。プレビューを再生すると歓迎文を最初から表示します。

内蔵プリセットはシネマ、シンプル、RPG、アドベンチャー、アクセシビリティ、バニラ風の六つです。名前を入力して独自のプリセットも保存できます。保存対象は見た目だけで、独自の名前はそのまま保ちます。まずエディターの作業コピーに追加されます。

**直接開いた場合、「適用」で HUD とプリセットを `config/cinematic_chat/` に保存します。設定画面から開いた場合、適用は親画面に変更を返すだけなので、親画面でも「保存」が必要です。** キャンセルまたは Esc は現在の画面の作業コピーを破棄します。親設定画面のキャンセルも子画面から返された変更を破棄します。
