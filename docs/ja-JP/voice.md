# ローカル疑似音声

[English](../en/voice.md) · [简体中文](../zh-CN/voice.md) · [日本語](../ja-JP/voice.md) · [한국어](../ko-KR/voice.md)

短い音を再生する機能で、音声合成ではありません。既定では無効で、プレイヤー・システム・NPC のフォールバックは「なし」です。

1. `/cchat voice` で有効にし、新規プロファイルを作ります。ID は `a-z`、`0-9`、`_`、`-`、`.` の 1～64 文字で重複不可です。
2. 話者の照合で名前または別名に `Steve` や `Alex` を追加します。UUID も利用できます。既定の順序は UUID、プロフィール名、表示名、別名、フォールバックです。装飾除去、大小文字、前後の空白の扱いを調整できます。元の名前は変更しません。
3. 短い OGG Vorbis または WAV PCM を `config/cinematic_chat/audio/` に置き、音声ファイル → 音声を追加で選びます。対象はこのディレクトリ内だけで、絶対パス、パストラバーサル、検出可能なシンボリックリンクによる逸脱を拒否します。テスト音の追加で同梱のオリジナル WAV・OGG を使えます。
4. モード、音量、ピッチ、変動、最短間隔、CJK 分割を設定します。試聴は開始音、発話テストは Steve と現在の言語の歓迎文で表示イベントを試します。
5. プロファイルを保存し、親の音声画面も保存します。設定画面から開いた場合は設定画面も保存します。キャンセル・Esc はその画面の作業コピーを破棄します。

五つのモードはオフ、字幕開始時、単語ごと、表示単位ごと、表示中の繰り返しです。新規プロファイルは表示単位ごと、65 ms、CJK 書記素二つごとが既定値で、空白と句読点を除外します。シャッフルバッグで可能な限り直前の音を避けます。即時表示では単位・単語ごとの音は最大一回にまとめます。

`/cchat voice list`、`/cchat voice test <voiceId>`、`/cchat voice assign Steve <voiceId>`、`/cchat voice reload` が使えます。assign は関連付けを保存します。音声の再読み込みは欠損・破損ファイルを交換した後の再試行にも使えます。`/cchat reload` は設定も読み直します。音声は `config/cinematic_chat/voices.json`、HUD と一般設定は別ファイルです。非同期で読み込み・デコードし、未準備の音は字幕を止めずにスキップします。消去、置換、チャット画面、無効化、ワールド変更は該当する音を停止します。
