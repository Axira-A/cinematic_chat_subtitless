# Minecraft 1.21.3

NeoForge 21.3.97 和 Fabric Loader 0.19.5 / API 0.114.1+1.21.3 分别编译、启动，临时世界场景通过。使用 1.21.2 的无参数模糊背景和带 FeatureFlagSet 的 GameRules 创建桥接。

Minecraft 聊天和 SoundEngine hook 保持 1.21.2 签名；required Mixin 在两次实际启动中执行成功。NeoForge 使用 FML 5.0.8，资源监听器仍为 `RegisterClientReloadListenersEvent`。官方没有独立的 1.21.3 primer 页面（该 URL 返回 404），按 1.21.2 primer 和该目标生成源码核对。

最终矩阵使用共享最新版场景，包含声线表单、原生 OGG 参数/生命周期、命令补全、后台配置重载与过滤撤回断言。客户端延后界面任务继续使用 1.21.2 起的 `schedule(Runnable)` 桥接。
