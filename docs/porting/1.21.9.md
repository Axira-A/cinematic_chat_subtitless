# Minecraft 1.21.9

NeoForge 21.9.16-beta、Fabric Loader 0.19.5 / API 0.134.1+1.21.9 已独立编译、启动并完成临时世界场景。完整验收及认证 Signed Chat 仍待验证。

按[官方 primer](https://docs.neoforged.net/primer/docs/1.21.9/)和该目标生成源码核对：最终 `ChatComponent.addMessage(Component, MessageSignature, GuiMessageTag)`、`deleteMessage(MessageSignature)` 和五参数 `render` 仍保持旧入口；`ChatListener.handleMessage(MessageSignature, BooleanSupplier)` 及 SoundEngine 的 channel、executor、loaded、destroy 桥接签名有效。

本目标新增适配：

- 原生 `MouseButtonEvent`、`KeyEvent` 转换为共享界面的逻辑坐标操作；鼠标转发保留修饰键和双击信息。Fabric 场景通过原生接口执行 HUD 拖动、宽度调整、缩放和 Apply。
- `KeyMapping.Category` 注册、Authlib `GameProfile.id()` / `name()`、`GuiGraphics.submitOutline`。
- `FontDescription` 字体资源和非资源字体的有界不透明引用桥接；原始 Component 不改写。
- `ChatScreen(String, boolean)` 的第二参数是草稿标志，测试新输入使用 false。屏幕识别仍采用类型判断。

测试源码不打入发布 JAR。已执行的原生音频断言包括 WAV 解码、channel 播放、缓冲分配及重载释放。
