# Minecraft 1.21.5

NeoForge 21.5.98 和 Fabric 0.19.5 / API 0.128.2+1.21.5 均已独立完成 Build、Launch 和新建临时世界自动场景，两个加载器各记录 37 项断言或场景结果。

已对 NeoForm 生成的源码核对最终 `ChatComponent.addMessage(Component,MessageSignature,GuiMessageTag)`、`deleteMessage(MessageSignature)`、`render(GuiGraphics,int,int,int,boolean)`、`ChatListener.handleMessage(MessageSignature,BooleanSupplier)` 和 SoundEngine channel/executor/destroy。这些 hook 保持参考版本签名。

FML 7 在 Minecraft 构造之前加载模组，构造函数中访问 Minecraft singleton 会导致客户端启动失败。该版本的 `ClientBootstrap` 使用 `FMLClientSetupEvent.enqueueWork` 初始化共享客户端，实际重跑通过。

ClickEvent 与 HoverEvent 改为具体记录类型；测试场景使用 `ClickEvent.SuggestCommand` 和 `HoverEvent.ShowText`，发布代码继续保留原始 Component 引用。资源索引为 24。

参考：[官方 1.21.5 primer](https://docs.neoforged.net/primer/docs/1.21.5/)。Signed Chat 仍待认证客户端与签名服务器验证。
