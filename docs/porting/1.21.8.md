# Minecraft 1.21.8

NeoForge 21.8.54 和 Fabric 0.19.5 / API 0.136.1+1.21.8 独立编译、启动并通过新建临时世界场景。

ChatComponent 最终三参数 addMessage、deleteMessage、五参数 render，ChatListener 带 BooleanSupplier 的 handler，以及 SoundEngine channel/executor/destroy 均已核对生成源码。继续使用 1.21.6 引入的二维 GuiPose 和背景模糊、截图桥接，依赖和最终 JAR 独立锁定版本。

本机使用可选 `-PneoFormCache=tools/.cache/neoformruntime` 将 NeoForm 的工作缓存放在 E 盘；官方 Minecraft 下载逐项通过 Mojang manifest SHA-1 验证，配置缓存不进入 Git。该路径只改变构建缓存位置。

参考：[官方 1.21.8 primer](https://docs.neoforged.net/primer/docs/1.21.8/)。完整扩展验收和 Signed Chat 认证场景仍待验证。
