# Minecraft 1.21

独立目标使用 NeoForge 21.0.167 或 Fabric Loader 0.19.5 / Fabric API 0.102.0+1.21。适配源码与 1.21.1 复用，但分别构建和启动；JAR metadata 声明精确的 Minecraft 版本。

已对生成的 Minecraft 1.21 源码核对：

| 入口 | 实际签名 |
|---|---|
| 最终历史写入 | `ChatComponent.addMessage(Component, MessageSignature, GuiMessageTag)` |
| 撤回 | `ChatComponent.deleteMessage(MessageSignature)` |
| gameplay render gate | `ChatComponent.render(GuiGraphics, int, int, int, boolean)` |
| profileless 上下文作用域 | `ChatListener.handleMessage(MessageSignature, BooleanSupplier)`，由 `handleDisguisedChatMessage(Component, ChatType.Bound)` 调用 |
| 音频释放 | `SoundEngine.destroy()`；channel / executor 字段类型与 1.21.1 相同 |

两个 Loader 的 required Mixin 均通过真实启动；临时世界场景通过。已认证 Signed Chat 与全面人工验收仍待执行。

迁移参考：[NeoForge 官方 1.21 primer](https://docs.neoforged.net/primer/docs/1.21/)。
