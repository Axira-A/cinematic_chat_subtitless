# Minecraft 1.21.11

NeoForge 21.11.45、Fabric Loader 0.19.5 / API 0.141.6+1.21.11 已独立完成编译、启动和临时世界场景。完整扩展验收、人工听感及已认证 Signed Chat 仍待验证。

根据[官方 primer](https://docs.neoforged.net/primer/docs/1.21.11/)和本目标生成源码，局部适配 `ResourceLocation → Identifier`、`GuiGraphics.renderOutline`。聊天捕获仍位于最终三参数 addMessage 的 TAIL，历史 Component、签名与消息标签均保留。

Fabric gate 精确指定 `render(GuiGraphics, Font, int, int, int, boolean, boolean)`，避免匹配新的私有绘制重载。focused 时保留原版聊天渲染与交互。NeoForge 继续通过可取消的 CHAT GUI layer 隐藏 gameplay 原版聊天。

测试世界初始化改用 `net.minecraft.world.level.gamerules.GameRules`，这只影响开发场景。SoundEngine channelAccess、executor、loaded 与 destroy 桥接签名再次核对，实际播放与缓冲释放断言通过。

可选离线镜像覆盖 Mojang 的元数据与库仓库，且需完整缓存 POM 父级。缓存文件不进入版本管理；普通网络构建仍使用官方仓库。
