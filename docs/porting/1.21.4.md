# Minecraft 1.21.4

NeoForge 21.4.158、Fabric Loader 0.19.5 / API 0.119.4+1.21.4 均独立编译并通过实际临时世界场景。

Minecraft 的 `ChatComponent.addMessage(Component,MessageSignature,GuiMessageTag)`、`deleteMessage(MessageSignature)`、`render(GuiGraphics,int,int,int,boolean)`、`ChatListener.handleMessage(MessageSignature,BooleanSupplier)`、SoundEngine channel/executor/destroy 已对生成源码核对，签名保持参考版本形式。

NeoForge 的资源监听器改为 `AddClientReloadListenersEvent.addListener(ResourceLocation,PreparableReloadListener)`，用版本 Loader 小桥接注册具名 listener。Fabric HUD 回调开始弃用，但当前 API 仍存在并通过实测；后续目标将迁移到 HUD element 注册。

该版本包含真实伪配音 Reveal Events → native channel 断言、Voice Profile 编辑器、小窗口滚动与 Cancel 隔离。Fabric 截图已确认声音预览区与操作按钮分开。signed chat 仍待认证环境。

参考：[官方 1.21.4 primer](https://docs.neoforged.net/primer/docs/1.21.4/)。
