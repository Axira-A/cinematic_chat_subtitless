# Minecraft 1.21.6

NeoForge 21.6.20-beta 和 Fabric 0.19.5 / API 0.128.2+1.21.6 均独立完成 Build、Launch 和新建临时世界自动场景。

生成源码中的最终聊天写入、删除、聊天 render gate、ChatListener 延迟处理以及 SoundEngine channel/executor/destroy 签名保持 1.21.5 形式。发布 JAR 的共享运行时、Java 21 字节码、client metadata 与必需 Mixin 检查通过。

GUI 使用 `Matrix3x2fStack`，由版本 `GuiPose` 桥接 pushMatrix/popMatrix、二维 translate 和 scale。共享渲染器及所有原生界面使用明确的 ARGB 颜色。背景模糊变为 `Screen.renderBlurredBackground(GuiGraphics)`，仅在 `CinematicScreen` 边界处理。

开发截图接口增加倍率参数，测试场景通过 `ScenarioPlatform` 以倍率 1 捕获。资源索引为 26。已检查 Fabric HUD 编辑截图中的中文字幕、边框、宽度/缩放手柄、辅助线和预览布局。

参考：[官方 1.21.6 primer](https://docs.neoforged.net/primer/docs/1.21.6/)。Signed Chat 仍待认证环境，完整扩展验收仍待补齐。
