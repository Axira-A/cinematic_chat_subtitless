# Minecraft 26.1

NeoForge 26.1.0.19-beta、Fabric Loader 0.19.5 / API 0.145.1+26.1 已分别完成编译、启动及临时世界场景。已验证 Java 25 客户端、共享核心 Java 21 字节码、HUD 工作副本和原生音频播放/释放。

依据 [Fabric 官方迁移说明](https://www.fabricmc.net/2026/03/14/261.html)、[NeoForge primer](https://docs.neoforged.net/primer/docs/26.1/) 和该目标生成源码：

- Fabric 使用 `net.fabricmc.fabric-loom`，无 mappings、modImplementation 或 remapJar；发布普通 jar。
- 唯一捕获点改为 `ChatComponent.addMessageToQueue(GuiMessage)` 的 TAIL。新的 private addMessage 在 visibleMessageFilter 失败时不写入历史，不能无条件在其 TAIL 捕获。客户端/服务器系统消息与玩家消息均通过实际 GuiMessageSource 提供结构化来源。
- `GuiMessage`、`GuiMessageTag` 移至 client.multiplayer.chat。权限过滤器变化清理字幕及声音，撤回按原始签名清理，不显示新的删除占位消息。
- Fabric gate 精确匹配 `extractRenderState(GuiGraphicsExtractor, Font, int, int, int, DisplayMode, boolean)`；只取消 BACKGROUND，保留 FOREGROUND 和 FOREGROUND_RESTRICTED。
- Fabric 使用 KeyMappingHelper、HudElementRegistry、ResourceLoader v1、ClientCommands。
- 共享界面与 renderer 的绘制 API 拼写差异由 `modern-adapter-sources.gradle` 在编译阶段转换；业务源码仍维护在同一处。聊天准入、原生输入和字体等行为差异使用该目标 Java override。生成文件不提交。
- 开发世界使用新的 DifficultySettings；GUI Scale 更新使用 resizeGui。这些变化仅用于 smoke 场景。

离线开发 profile 的 Signed Chat 不视为认证验证。全矩阵自动回归与完整人工扩展验收分别记录在 [验证报告](../validation.md) 和 [验收清单](../acceptance.md)。
