# Minecraft 1.21.7

NeoForge 21.7.25-beta 和 Fabric 0.19.5 / API 0.129.0+1.21.7 独立编译、启动并通过新建临时世界场景。

已检查生成的 ChatComponent、ChatListener、SoundEngine 和 Screen 源码：最终三参数 addMessage、deleteMessage、五参数 chat render、带 BooleanSupplier 的延迟 handler、channel/executor/destroy 与 1.21.6 相同。沿用二维 GuiPose、GuiGraphics 背景模糊及带倍率的开发截图桥接。该目标使用自己的加载器依赖和 exact Minecraft metadata，没有复用跨版本 JAR。

参考：[官方 1.21.7 primer](https://docs.neoforged.net/primer/docs/1.21.7/)。完整扩展验收和 Signed Chat 认证场景仍待验证。
