# Minecraft 1.21.10

NeoForge 21.10.64、Fabric Loader 0.19.5 / API 0.138.4+1.21.10 已分别完成编译、启动与临时世界场景。完整扩展验收和认证 Signed Chat 待验证。

核对[官方 primer](https://docs.neoforged.net/primer/docs/1.21.10/)及 21.10.64 生成源码后，本模组使用的聊天最终三参数入口、deleteMessage、五参数 render、ChatListener BooleanSupplier handler、原生输入事件、FontDescription 与音频桥接保持 1.21.9 的签名。两个目标分别生成 JAR，并检查 metadata、必需 Mixin 和共享核心字节码版本。

场景通过原生鼠标事件测试 HUD 工作副本、拖动、调宽、缩放与 Apply/Cancel。WAV 加载、原生播放、重载释放、逐字伪配音和声线编辑取消断言通过。
