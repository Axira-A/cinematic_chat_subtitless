# Minecraft 26.1.1

独立目标使用 NeoForge 26.1.1.15-beta 与 Fabric API 0.145.4+26.1.1 / Loader 0.19.5。两个加载器均已实际编译、启动并进入临时世界；增强验收状态由最终矩阵单独记录，未根据 26.1 的结果推断。

没有取得专属 patch primer；核对的是此目标生成的 `minecraft-patched-26.1.1.15-beta-sources.jar`，包括 ChatComponent、ChatListener、Screen、GuiGraphicsExtractor、SoundEngine 和字体类。沿用已核对的 26.1 架构边界，不沿用旧 1.21.x 的聊天入口。

- 最终历史写入是 `addMessageToQueue(GuiMessage)`；捕获其 TAIL。
- `setVisibleMessageFilter(Predicate<GuiMessage>)` 可能拒绝消息，变化后清理字幕和音频。
- Fabric 使用带 `ChatComponent.DisplayMode` 的 `extractRenderState`，只 gate BACKGROUND。
- 原生鼠标/按键对象与 extractor 绘制 API 在此目标分别编译检查。
- 延后打开客户端界面使用 `BlockableEventLoop.schedule(Runnable)`。
- SoundEngine channelAccess/executor/loaded/destroy 仍可桥接；实际原生声音测试独立执行。
- Java 25、未混淆 Loom、共享 Java 21 字节码与精确版本 metadata 单独验证。

26.1 的主要设计依据见 [26.1 记录](26.1.md)。认证 Signed Chat 和人工听感仍需外部验收。
