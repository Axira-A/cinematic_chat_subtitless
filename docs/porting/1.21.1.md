# 1.21.1 hook 审计

Minecraft 官方命名，Java 21。NeoForge 21.1.252、Fabric Loader 0.19.5、Fabric API 0.116.17+1.21.1、Loom 1.15.5。

| 入口 | 实际签名/用途 |
| --- | --- |
| 历史写入 | `ChatComponent.addMessage(Component, MessageSignature, GuiMessageTag): void`，TAIL 捕获 |
| 撤回 | `ChatComponent.deleteMessage(MessageSignature): void`，通知当前字幕移除 |
| 原版绘制 | `ChatComponent.render(GuiGraphics,int,int,int,boolean): void`，focused/ChatScreen 保留 |
| NeoForge 隐藏 | `RenderGuiLayerEvent.Pre`，只取消 `VanillaGuiLayers.CHAT` |
| NeoForge 上下文 | `ClientChatReceivedEvent.Player/System`，最低优先级，取消事件不接收 |
| Fabric 上下文 | `ClientReceiveMessageEvents.CHAT/GAME`，只提供上下文 |
| Fabric profileless | `ChatListener.handleDisguisedChatMessage` 调用私有 `handleMessage(MessageSignature,BooleanSupplier)`；在实际 delayed handler 周围保留 Bound ChatType |
| NeoForge tick | `net.neoforged.neoforge.client.event.ClientTickEvent.Post` |
| NeoForge HUD | `RenderGuiEvent.Post` |
| 音频解码 | `JOrbisAudioStream(InputStream)`，`read(int)` 读取 PCM |
| Native 声道 | `SoundEngine.channelAccess`、`executor`、`loaded`，只读 accessor |
| 设备生命周期 | `SoundEngine.destroy(): void` HEAD，在 vanilla device cleanup 前释放本地缓冲 |
| 客户端结束 | `Minecraft.close(): void` HEAD，清空并关闭后台工作器 |

三参数 addMessage 内，vanilla 先生成 GuiMessage、写 display queue 和 allMessages；TAIL 后才入字幕队列。完整 Component、签名引用、GuiMessageTag 都保留。最小 Mixin 不修改 addMessage 参数、返回值或任何网络处理。

profileless 上下文不能根据格式化文本猜测。Fabric 的 GAME 事件没有 Bound ChatType，因此版本 Mixin 给 vanilla 原 handler 增加一个透明上下文作用域，仍执行原 handler 并返回原结果；拒绝的消息没有历史写入，也没有字幕。

来源：[Fabric Message API 源码](https://github.com/FabricMC/fabric/tree/1.21.1/fabric-message-api-v1)、本机构建生成的 Minecraft 1.21.1 源码、NeoForge 21.1.252 sources JAR。26.1 聊天入口和权限发生边界变化，不能沿用这些签名，见 [NeoForge 26.1 primer](https://docs.neoforged.net/primer/docs/26.1/) 与 [Fabric 迁移说明](https://www.fabricmc.net/2026/03/14/261.html)。
