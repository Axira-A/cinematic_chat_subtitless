# Minecraft 26.1.2

独立目标使用 NeoForge 26.1.2.112 与 Fabric API 0.155.3+26.1.2 / Loader 0.19.5。两个加载器均已实际编译、启动并进入临时世界；完整状态按此目标的 JSON 和命令日志记录。

没有取得专属 patch primer；以 `minecraft-patched-26.1.2.112-sources.jar` 核对 ChatComponent、ChatListener、GuiMessageSource、Screen、GuiGraphicsExtractor、Minecraft、KeyMapping、SoundEngine 和字体 API。

捕获在 `addMessageToQueue(GuiMessage)` 写入历史之后。权限过滤器变化清理本地字幕；Fabric render gate 精确匹配 DisplayMode 签名，保留前景 ChatScreen 模式。原生输入、字体、音频和客户端延后任务使用已核对的显式 API 家族及共享 override；共享业务通过 GuiCanvas、CinematicScreen 和 ScenarioPlatform 调用版本桥接，不生成 Java 源码。

此目标引入的资产索引和游戏库按自身官方清单处理。首次 NeoForm 解编译遇到本机 Windows 虚拟内存不足，改为串行处理并释放闲置的构建进程后完成；失败运行不计为成功，后续独立 build/run 才计入矩阵。

Java 25 adapter、共享 Java 21 核心、精确版本 metadata、客户端世界、HUD 和原生声音生命周期均单独检查。认证 Signed Chat、人工听感和全部人工扩展验收不据此标记完成。
