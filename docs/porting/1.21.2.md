# Minecraft 1.21.2

使用 NeoForge 21.2.1-beta，或 Fabric Loader 0.19.5 / API 0.106.1+1.21.2。两个目标均独立编译并通过临时世界场景。

生成源码已核对 `ChatComponent.addMessage(Component, MessageSignature, GuiMessageTag)`、`deleteMessage(MessageSignature)`、`render(GuiGraphics,int,int,int,boolean)` 以及 SoundEngine 的 channel/executor 字段和 `destroy()`；这些 hook 保持参考版本签名。

真正发生的适配差异：`Screen.renderBlurredBackground(float)` 改为无参数方法，集中在版本 Screen 基类；客户端延后任务从 `tell(Runnable)` 变为 `schedule(Runnable)`，由目标 ClientTasks 桥接，防止 ChatScreen 发送后关闭覆盖新界面；测试场景的 `GameRules` 构造器新增 FeatureFlagSet 参数。配置和声线界面的业务源码继续共享。

参考：[NeoForge 官方 1.21.2 primer](https://docs.neoforged.net/primer/docs/1.21.2/)。Signed Chat 已认证验证仍待外部测试环境，beta 加载器的原版资源警告记录在开发日志中。
